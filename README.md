# lib_base

## English (United States)

Fork of [desktop-app/lib_base][upstream], used by [fortsoft-eu/tdesktop][parent]:
Telegram Desktop 7.1.3 with a Windows 2000-style GUI.

Shared C++ utilities for timing, threading, platform integration, and
other common application tasks. Local changes adjust timer construction
and the connection used for clock adjustments.

Build this library as part of the parent project, not as a standalone application.
